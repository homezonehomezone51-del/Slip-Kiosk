# Slip Kiosk - code repo (GitHub Pages)

Is repo mein exe ka asli code hai. Settings > Pages > Branch `main`, folder `/ (root)` > Save.
Pages ka link (https://USER.github.io/REPO/) exe repo ke `loader.py` mein daalna hai.

Code badalna: `slip_bridge.py` / `slip_kiosk_app.py` GitHub par edit karke Commit karein.
1-2 minute baad Pages update ho jata hai, aur exe agli dafa start hone par naya code utha leta hai.
